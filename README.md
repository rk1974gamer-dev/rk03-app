# RK-03 APP Launcher & Web Hub

Aplicação oficial e central de controle para o ecossistema **RK-03 Tech & Gaming PC** (`https://www.rk-03assemblerpc.com`).

---

## ⚡ Funcionalidades Principais

- **Início & Contato Direto**: Acesso rápido ao canal VIP no WhatsApp (`(19) 996336407`), ligação telefônica, mapa da oficina em Campinas/SP e portal web.
- **Loja & Produtos**: Catálogo de cadeiras ergonômicas, gabinetes gamer, periféricos e peças com preços em Real (R$) e envio para todo o Brasil.
- **Planos de Suporte (Prime & VIP)**: Assinaturas periódicas de manutenção preventiva, suporte 24/7 com montador especialista e 14 dias de teste gratuito.
- **Galeria de Setups Custom**: Fichas técnicas completas com processador, placa de vídeo, refrigeração líquida e orçamento estimado de builds reais.
- **App Hub & Launcher**: Calculadora de consumo/TDP para montagem de computadores, estimador de FPS para jogos competitivos (CS2, Valorant, Warzone) e atalhos de ferramentas.
- **Painel Agente Lion**: Monitor de integridade, uptime e rotina de sincronização de dados via JSON REST.

---

## 🛠️ Execução

```bash
npm install
npm run dev
```

Porta padrão: `3000` (host: `0.0.0.0`)
